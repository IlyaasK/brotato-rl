# Brotato item-effect data contract

Generated by `ocean/brotato/extract_items.py`.  Companion headers:
`ocean/brotato/brotato_items.h` (`BtItem`, `BT_ITEMS`, `BT_ITEM_EFFECTS`)
and `ocean/brotato/brotato_item_effects.h` (structured graph).  Every
value is resolved from the recovered campaign + Abyss DLC resources.

The legacy stat ids are the canonical core ids 0..12: 0 max_hp, 1
hp_regeneration, 2 armor, 3 speed, 4 dodge, 5 percent_damage, 6
melee_damage, 7 ranged_damage, 8 elemental_damage, 9 crit_chance, 10
luck, 11 crit_damage, 12 harvesting.  Id 12 reaches the core through its
`default:` branch, so the legacy pool now emits ids up to 12 where the
former 147-item table only used 0..10 -> the core observation's dominant
stat feature (`dom / 10`) can now exceed 1.  Every id also appears in the
structured graph with its interned key for exact handling.

## Dynamic stat links

`BT_ITEM_STAT_LINKS` / `BT_NITEM_STAT_LINKS` replace the hand-maintained
`BtStatLink` indices in `brotato_state.h` (75/96/117), which no longer
match this pool's item order (the pool is the complete 247-item campaign +
DLC set, not the former 147-item subset).  Fields:

| field | semantics |
|---|---|
| `item` | `BT_ITEMS` index owning the link |
| `target` | core stat id gained (`BT_STAT_NONE` if outside 0..12) |
| `source` | core stat id scaled (`BT_STAT_NONE` if outside 0..12) |
| `value` | gain per `nb` units of the source stat |
| `nb` | `nb_stat_scaled` (`int`: may be -1, the game's per-unit sentinel) |
| `perm_stats_only` | `GainStatForEveryStatEffect.perm_stats_only` |
| `target_key` | `BT_ISTR_*` interned target stat key |
| `source_key` | `BT_ISTR_*` interned source stat key |

## Shop bans

- `BT_ENDLESS_BANNED_ITEMS` / `_N`: `ItemService.banned_items_for_endless`.
- `BT_BULL_BANNED_ITEMS` / `_N`: Bull `banned_items`
  (item_jelly, item_nail, item_crystal, item_coffee, item_seashell, item_glasses, item_community_support, item_tardigrade).
- `BT_BULL_BANNED_GROUP_MASK`: Bull `banned_item_groups` (lifesteal).
- `BT_BULL_WANTED_TAGS` / `_N`: Bull `wanted_tags` (interned ids).
